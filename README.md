# Easy Tagger

윈도우 탐색기에서 파일을 드래그 & 드롭하거나 클릭하여 파일명 태그(`[태그]`, `#태그`)를 빠르고 간편하게 추가·제거·정리하는 PyQt6 기반 데스크톱 유틸리티입니다.

---

## 주요 기능

### 1. 드래그 & 드롭 태깅 및 일괄 편집
* **버튼 위 파일 드롭**: 단일/다중 파일을 태그 버튼에 드롭하여 태그를 즉시 적용합니다.
* **창 빈 공간 파일 드롭**: 편집할 파일들을 불러온 뒤 태그 버튼 클릭으로 일괄 추가/제거할 수 있습니다.
* **시각적 태그 상태 표시**:
  * `✓ 태그`: 모든 활성 파일에 적용됨 (클릭 시 일괄 제거)
  * `◐ 태그`: 일부 활성 파일에 적용됨 (클릭 시 전체 추가)
  * `+ 태그`: 미적용 상태 (클릭 시 전체 추가)

### 2. 대괄호(`[태그]`) 및 해시태그(`#태그`) 지원
* 파일 특성에 따라 대괄호 형태와 해시태그 형태를 선택하거나 혼합하여 사용할 수 있습니다.
* 파일명 내 단어에 포함된 `#`(`C#`, `트랙#1`)은 유지하고, 공백으로 구분된 독립 태그(` #4K `)만 정밀하게 파싱합니다.
* 태그 생성 시 이름이 `#`으로 시작하면 자동으로 해시태그 형태로 설정됩니다.

### 3. 태그 위치(접두/접미) 및 그룹 설정
* 태그별로 파일명 앞(접두, Prefix) 또는 뒤(접미, Suffix) 위치를 개별 지정할 수 있습니다.
* 그룹 우클릭 메뉴의 **그룹 설정**에서 그룹 이름을 변경하거나, 그룹 내 모든 태그의 위치와 형태를 한 번에 일괄 통일할 수 있습니다.

### 4. 속성 태그 (동일 키 값 교체 및 런타임 입력)
* **고정 속성 태그** (`-fps 60`): 파일명에 동일한 `-키`가 이미 존재하면 기존 값을 새 값(`60`)으로 자동 교체합니다.
* **입력형 속성 태그** (`-score ?`): 태그 클릭 또는 파일 드롭 시 입력 대화상자가 표시되며, 입력한 값으로 태그가 적용됩니다.

### 5. 미등록 태그 자동 감지
* 파일명에 존재하지만 프로그램에 등록되어 있지 않은 태그를 자동으로 추출하여 상단 임시 그룹에 표시합니다.
* 임시 감지 태그는 프로그램 재시작 시 영구 저장되지 않고 초기화됩니다.

### 6. 순서 편집 및 실행 취소
* `Ctrl` + 좌클릭 드래그로 태그 순서 변경, 다른 그룹으로 태그 이동, 그룹 상하 순서 변경을 지원합니다.
* `Ctrl + Z` 단축키를 통해 최근 작업한 파일명 변경 작업을 이전 상태로 일괄 되돌릴 수 있습니다.

## 조작 요약

| 조작 대상 | 입력 방식 | 동작 설명 |
| :--- | :--- | :--- |
| **즉시 태그 적용** | 파일 드래그 ➔ **태그 버튼 위 드롭** | 해당 파일(단일/다중)에 태그 즉시 적용 |
| **파일 로드 & 토글** | 파일 드래그 ➔ **창 빈 공간 드롭** | 파일 로드 후 태그 버튼 좌클릭으로 추가/제거 토글 |
| **태그 / 그룹 이동** | **`Ctrl` + 좌클릭 드래그** | 태그 순서 변경, 소속 그룹 변경, 그룹 간 순서 변경 |
| **메인 메뉴 호출** | 상단 바 우측 **`☰` 버튼 클릭** | 실행 취소, 항상 위에 고정, 환경 설정, 도움말 |
| **그룹 추가** | 상단 바 우측 **`새 그룹 추가` 아이콘** | 신규 태그 그룹 생성 |
| **컨텍스트 메뉴** | 태그 / 그룹 영역 **우클릭** | 태그 수정·복제·삭제 / 그룹 설정(이름·속성통일)·삭제 |
| **단축키** | `Ctrl + Z` / `Ctrl + ,` / `F1` | 실행 취소 / 환경 설정 열기 / 도움말 열기 |

## 실행 및 빌드

* **환경 요구사항**: Python 3.10+, PyQt6 6.12+
* **실행**:
  ```bash
  python main.py
  # 또는 run.bat 실행
  ```
* **전체 단위 테스트**:
  ```bash
  python -m unittest discover -s tests -p "test_*.py" -v
  ```
* **실행 파일 빌드 & 패키징**:
  ```bash
  # build.bat 실행 (dist/EasyTagger.exe 및 zip 배포 압축파일 생성)
  ```
