# Easy Tagger

윈도우 탐색기에서 파일(단일·다중)을 드래그 & 드롭하거나 버튼을 클릭해 파일명 태그(`[태그]`)를 빠르게 추가·제거하는 데스크톱 유틸리티입니다.

---

## ✨ 핵심 기능

### 1. 드래그 드롭 태깅 & 다중 파일 일괄 편집
* **버튼 위 파일 드롭**: 탐색기에서 하나 또는 여러 개의 파일을 태그 버튼에 드롭하면 즉시 일괄 적용되고, 드롭한 파일 전체가 활성 편집 상태로 유지됩니다.
* **창 위 파일 드롭 & 토글 편집**: 파일을 창에 드롭해 불러온 뒤, 태그 버튼을 클릭해 즉시 켜거나 끕니다.
  * **전체 적용 (`✓ 태그`)**: 솔리드 채움 상태로 표시되며, 클릭 시 모든 파일에서 태그 일괄 제거
  * **일부 적용 (`◐ 태그`)**: 점선 테두리 상태로 표시되며, 클릭 시 모든 파일에 태그 일괄 추가
  * **미적용 (`태그`)**: 태그 고유 색상의 아웃라인 테두리 버튼으로 표시되어 식별이 용이하며, 클릭 시 모든 파일에 태그 일괄 추가

### 2. 미등록 태그 세션 감지
* 파일명에 등록되지 않은 태그가 있으면 최상단 **`감지된 태그`** 그룹에 자동으로 추출·표시되어 즉시 사용할 수 있으며, 프로그램을 재시작하면 임시 감지 태그는 자동으로 초기화(삭제)됩니다.

### 3. 통합된 태그 작성 체계 (일반 · 속성 태그 자동 인식)
태그 이름 입력칸 하나에서 작성 형식에 따라 일반 태그와 속성(`Key-Value`) 태그를 자동으로 구분합니다:
* **일반 태그** (`여행`, `4K`): 파일명에 그대로 추가·제거됩니다.
* **고정 속성 태그** (`-fps 60`): 파일에 동일한 키(`-fps`)가 이미 있으면 값만 `60`으로 교체합니다.
* **입력형 속성 태그** (`-score ?`): 드롭 또는 클릭 시 즉시 포커싱된 값 입력창이 열리며, 값 입력 후 `Enter`를 누르면 적용됩니다.

### 4. 그룹 및 태그 이동 (`Ctrl` + 드래그)
* 그룹 단위로 태그를 분류하고 접기/펼치기, 추가/수정/복제/삭제할 수 있습니다.
* `Ctrl`을 누른 채 드래그하여 **태그 순서 변경**, **다른 그룹으로 태그 이동**, **그룹 간 순서 변경**이 가능합니다.

### 5. 설정 템플릿 관리 & 자체 자동 복구 (Self-Healing)
* 개인 설정 파일인 `config.json`은 `.gitignore`에 등록되어 보존되며, 초기 템플릿인 `config.init.json`을 통해 배포 및 버전 관리가 이루어집니다.
* `config.json`이나 `config.init.json`이 삭제되더라도, 프로그램에 내장된 자체 복구 로직이 표준 기본 설정을 자동으로 재생성하여 안정적으로 동작합니다.

## ⌨️ 조작 요약

| 동작 | 조작 방법 |
| :--- | :--- |
| **즉시 태그 적용 (단일/다중)** | 탐색기 파일을 **태그 버튼 위**로 드롭 |
| **파일 불러오기 & 일괄 토글** | 탐색기 파일을 **창 빈 공간**에 드롭 후 **태그 버튼 좌클릭** |
| **주요 액션 실행** | 상단 바 우측 아이콘 클릭 (**그룹 추가**, **실행 취소**, **핀 고정**, **설정**) |
| **태그 / 그룹 이동** | **`Ctrl` + 좌클릭 드래그** (태그 순서·소속 그룹 변경, 그룹 순서 변경) |
| **컨텍스트 메뉴** | **우클릭** (태그: 수정·복제·삭제 / 그룹: 이름 변경·삭제 / 빈 공간: 전역 메뉴) |
| **실행 취소 / 환경 설정** | `Ctrl + Z` (다중 파일 일괄 복원) / `Ctrl + ,` |

## 🚀 실행 및 빌드

```bash
# 실행 (또는 run.bat 더블클릭)
python main.py

# 테스트 실행
python -m unittest discover -p "test_*.py" -v

# 단일 실행 파일(.exe) 빌드
pyinstaller -w -F --icon="assets/icon.ico" --name "EasyTagger" main.py
```
