# Easy Tagger

윈도우 탐색기에서 파일을 드래그 & 드롭하거나 클릭하여 파일명 태그(`[태그]`)를 간편하게 추가·제거하는 PyQt6 기반 데스크톱 유틸리티입니다.

---

## 📌 핵심 기능

### 1. 드래그 & 드롭 태깅 및 일괄 편집
* **버튼 위 파일 드롭**: 단일/다중 파일을 태그 버튼에 드롭 시 즉시 태그 적용 및 활성 편집 목록 등록
* **창 빈 공간 파일 드롭**: 편집할 파일들을 불러온 후 태그 버튼 클릭으로 일괄 토글
* **3단계 시각적 태그 상태 표시**:
  * `✓ 태그` (전체 적용): 솔리드 채움 상태, 클릭 시 모든 활성 파일에서 해당 태그 일괄 제거
  * `◐ 태그` (일부 적용): 점선 테두리 상태, 클릭 시 모든 활성 파일에 해당 태그 일괄 추가
  * `+ 태그` (미적용): 태그 고유 색상의 아웃라인 테두리, 클릭 시 모든 활성 파일에 해당 태그 일괄 추가

### 2. 세션 기반 미등록 태그 자동 감지
* **자동 추출**: 파일명에 존재하지만 프로그램에 등록되지 않은 태그를 자동 감지
* **임시 그룹 생성**: 최상단 `감지된 태그` 그룹에 자동 추가되어 즉시 토글 및 제거 가능
* **세션 휘발성**: 프로그램 재시작 시 임시 감지 태그는 설정에 영구 저장되지 않고 자동 초기화

### 3. 통합 태그 입력 체계 (단일 입력창에서 자동 판별)
* **일반 태그** (`여행`, `4K`): 파일명에 `[여행]` 형태로 단순 추가/제거
* **고정 속성 태그** (`-fps 60`): 파일명에 동일한 `-키`가 이미 있을 경우 기존 값을 새 값(`60`)으로 자동 교체
* **입력형 속성 태그** (`-score ?`): 태그 클릭 또는 드롭 시 실시간 값 입력 대화상자가 표시되며, 입력값으로 적용

### 4. 직관적인 UI 제어 및 마우스 제스처
* **그룹 및 태그 이동**: `Ctrl` + 좌클릭 드래그로 태그 순서 변경, 타 그룹으로 태그 이동, 그룹 상하 순서 변경
* **다중 파일 일괄 실행 취소**: `Ctrl + Z`로 최근 작업 파일명을 이전 상태로 일괄 복원
* **컨텍스트 메뉴**: 우클릭을 통해 태그(수정/복제/삭제) 및 그룹(태그추가/이름변경/삭제) 메뉴 호출
* **시스템 맞춤 테마**: OS 다크/라이트 모드 자동 동기화 및 Windows DWM 네이티브 타이틀바 색상 연동

### 5. 설정 템플릿 관리 및 자체 자동 복구 (Self-Healing)
* **내장 기본값 기반 자동 설정**: `config.json` 부재 시 코드 내장 기본 템플릿을 기반으로 자동 생성
* **무중단 자가 복구**: 설정 파일이 손상되거나 삭제되어도 내장 기본값으로 자동 재생성

## ⌨️ 조작 요약

| 조작 대상 | 입력 방식 | 동작 설명 |
| :--- | :--- | :--- |
| **즉시 태그 적용** | 파일 드래그 ➔ **태그 버튼 위 드롭** | 해당 파일(단일/다중)에 태그 즉시 적용 및 활성화 |
| **파일 로드 & 토글** | 파일 드래그 ➔ **창 빈 공간 드롭** | 파일 활성화 후 태그 버튼 좌클릭으로 추가/제거 토글 |
| **태그 / 그룹 이동** | **`Ctrl` + 좌클릭 드래그** | 태그 순서 변경, 소속 그룹 변경, 그룹 간 순서 변경 |
| **메인 메뉴 호출** | 상단 바 우측 **`☰` 버튼 클릭** | 실행 취소, 항상 위에 고정, 환경 설정, 도움말 메뉴 |
| **그룹 추가** | 상단 바 우측 **`새 그룹 추가` 아이콘** | 신규 태그 그룹 생성 대화상자 호출 |
| **컨텍스트 메뉴** | 태그 / 그룹 영역 **우클릭** | 태그 수정·복제·삭제 / 그룹 이름 변경·삭제 |
| **단축키** | `Ctrl + Z` / `Ctrl + ,` / `F1` | 실행 취소 / 환경 설정 열기 / 도움말 열기 |

## 🛠️ 실행 및 빌드

* **환경 요구사항**: Python 3.10+, PyQt6 6.12+
* **실행**:
  ```bash
  python main.py
  # 또는 run.bat 실행
  ```
* **전체 단위/통합 테스트**:
  ```bash
  python -m unittest discover -s tests -p "test_*.py" -v
  ```
* **단일 실행 파일(`.exe`) 빌드**:
  ```bash
  python -m PyInstaller --clean --noconsole --onefile --paths="." --icon="assets/icon.ico" --name="EasyTagger" --add-data="assets;assets" main.py
  # 또는 build.bat 실행 (dist/EasyTagger.exe 생성)
  ```
